# 人格解体-现实解体障碍知识库

欢迎来到 DPDR Wiki，这里是一个专注于**人格解体（Depersonalization）**和**现实解体（Derealization）**障碍的科普知识库。

## 什么是 DPDR？

DPDR 是 **Depersonalization-Derealization Disorder** 的缩写，指人格解体-现实解体障碍。这是一种被广泛误解的心理现象，患者会感到：

- **人格解体**：感觉自己与自己的思想、情感或身体疏离，像在"旁观"自己
- **现实解体**：周围世界变得不真实、模糊或像梦一样
