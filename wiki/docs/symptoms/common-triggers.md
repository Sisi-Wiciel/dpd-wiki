# 常见触发因素

了解个人触发因素可以帮助你更好地预防和管理症状。

## 心理社会因素

- **压力**：工作压力、人际关系冲突、经济困难
- **创伤**：事故、目击暴力、失去亲人
- **孤独**：长期社交隔离或回避
- **完美主义**：过度自我要求

## 生理因素

- **睡眠不足**：长期失眠或睡眠质量差
- **脱水**：没有喝足够的水
- **低血糖**：长时间不进食
- **过度换气**：快速浅呼吸（常见于焦虑）

## 环境因素

- **拥挤或密闭空间**：地铁、电梯
- **强光或强声**：迪斯科、烟花
- **过度使用电子设备**：长时间屏幕暴露

## 物质因素

- **咖啡因过量**：大量咖啡或能量饮料
- **酒精**：饮酒或戒断
- **大麻**：使用或戒断
- **某些药物**：如分离性麻醉剂

## 如何应对已知触发因素

1. **记录触发因素日记**：记录何时、何地、什么活动后出现症状
2. **制定应对计划**：识别触发因素后，准备好接地技术
3. **逐步暴露**：在安全环境下逐渐接触触发因素
4. **寻求支持**：与理解你的人讨论

:::tip 预防胜于治疗
建立规律作息、管理压力、保持社交连接是长期减少发作频率的关键。
:::
